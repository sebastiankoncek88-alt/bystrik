# Bystrík 🧸

Hravá apka na učenie pre 1. až 4. ročník ZŠ: matematika, slovenčina, prehľad (príroda, svet, angličtina), čítanka, minihry, avatar s odmenami a rodičovský účet.

Apka beží na GitHub Pages: otvor `index.html` cez adresu stránky. Zdrojové súbory sú v priečinku `src/`. Novú verziu zostavíš príkazom `./build_web.sh`, potom skopíruj obsah priečinka `web/` do koreňa repozitára.
